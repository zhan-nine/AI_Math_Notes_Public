## 这是一本什么样的书

与课堂速记不同，本书按数学系教材的逻辑展开，每一节通常遵循同一条线索：

**定义 → 性质 → 引理 → 定理 → 证明 → 直观解释 → 例子 → AI 应用 → 小结 → 习题**

由此形成三条主要特点：

- **理论完整**：核心结论都给出证明，并说明用到哪些定义、定理或假设。
- **几何直观**：定理之后配「直观解释」，用几何、概率或数值计算的语言说明它意味着什么。
- **AI 关联**：每章都回答「这个数学结构在机器学习里对应什么」。

内容取舍的原则是**课件定范围，教材定深度**——课程课件确定教学范围与章节次序，经典教科书补充理论细节。

## 前言：人工智能时代，学习数学的新范式

人工智能时代，我们应该如何学习数学？需要学习多少数学？当机器已经能够完成越来越复杂的计算、推导乃至证明时，人为什么还要花费大量时间学习数学？人工智能又会怎样改变数学教育和数学研究？

这些问题目前并没有标准答案。我们希望通过这份教材对它们的进行一次回答，这也同样是一场仍在进行中的教学实验。

这场实验来自一个很朴素的起点：十几位仍在求学阶段的博士研究生，因为共同学习数学、共同面对人工智能带来的变化而聚集在一起，希望一起整理一份更适合今天学习方式的数学教材。我们中的每个人都有自己的研究方向和学习经历，对数学也有不同的理解。编写这份教材的过程，本身也是一个不断讨论、互相质疑、反复修改的过程。

因此，这不是一份独立完成的教材，也不是一份试图一次性写完的知识汇编。它更像是十几位学习者共同留下的一份学习记录。我们希望把这种共同整理、共同讨论和共同审查的过程，也留给后来阅读这份教材的人。

### 从 AlphaGo 之后说起

2016 年 3 月，AlphaGo 战胜围棋世界冠军李世石。那场比赛后来常常被视为人工智能发展史上的一个标志性事件。许多人第一次如此直观地意识到：一些长期以来被认为高度依赖经验、直觉和人类智慧的活动，机器也可能达到甚至超过人类顶尖水平。

十年过去，类似的变化已经发生在越来越多的领域。数学作为一个大量使用形式化语言、明确规则和严密推理的学科，也正在经历类似的变化。

其实，人们很早以前就在思考机器最终能够走多远。1950 年，Alan Turing 在著名论文 *Computing Machinery and Intelligence* 的结尾写道：

> “We can only see a short distance ahead, but we can see plenty there that needs to be done.”

我们只能看见前方不远的地方，但仅仅在那里，就已经有许多事情需要去做。[1]

七十多年过去，这句话所表达的谨慎与开放，依然适合我们今天面对人工智能时的处境。

计算机参与数学并不是今天才开始的。数值计算、符号计算、计算机辅助证明，以及计算数学和数据密集型科学的发展，都已经深刻改变了数学和科学研究。近年来，大语言模型、自动定理证明、证明辅助工具以及形式化数学的发展，又进一步扩大了机器参与数学活动的范围。计算、检索、构造例子、寻找反例、检查推导、形成猜想乃至尝试证明，都可以不同程度地获得机器的帮助。

我们正在逐渐进入一个新的阶段：数学活动越来越可能成为人与计算工具、人工智能共同工作的过程。

当接近数学知识的门槛开始降低，当一篇原本需要扎实的数学基础、花费数小时才能读懂的论文，可以借助大语言模型在几分钟内获得一个初步而通俗的解释；当人工智能开始参与形式化证明、猜想生成和数学研究，一些过去只有经过长期专业训练才能开展的数学活动，也越来越多地得到机器的帮助。我们由此面对两个更加根本的问题：

**如果机器越来越会做数学，我们为什么还要学习数学？**

**如果人与人工智能共同参与数学活动正在成为可能，我们又应该怎样学习数学？**

### 为什么还要学习数学？

一个直接的回答是，现代人工智能本身建立在大量数学理论之上。从理解和研究人工智能的角度看，数学仍然具有基础性的作用。

线性代数、概率论、统计学、最优化、信息论等数学工具，是理解现代机器学习的重要基础。本书主要讨论其中与人工智能基础课程关系最密切的线性代数、概率论与最优化，并在需要时涉及相关数学工具。与此同时，人工智能中仍然存在大量“实践中有效、理论上尚未被充分理解”的现象。一个模型为什么有效，在什么条件下有效，又会在什么条件下失效，仍然是数学和人工智能研究中十分重要的问题。

但数学的价值还可以从更宽的范围来理解。

人工智能处理的是信息，而数学本身就是人类发展出来的一套极为精炼的信息表达、组织和推理体系。定义试图准确划定概念的边界；定理描述条件与结论之间的关系；证明则把这种关系转化为可以一步一步检查的推理。

数学训练真正留下来的，除了求导、积分、矩阵分解或者概率计算这些枯燥的技巧，还包括一些更基本的习惯：面对一个问题，先弄清研究的对象；面对一个概念，先检查它的定义；面对一个结论，先寻找它成立的条件；面对一段推导，逐步检查其中的依据；面对一个看似漂亮的答案，再问一句：有没有反例？

George Pólya 长期研究数学中的问题求解和发现。他曾强调，数学教育应当系统地给学生机会，让他们自己去发现。[2]

在人工智能时代，这句话可能具有新的含义。过去，“自己发现”常常意味着人类独立完成计算和推导；今天，它还可以意味着在人工智能辅助下自己提出问题、识别条件、检查论证、寻找反例、比较不同解释，并判断机器给出的答案是否真正解决了原来的问题。

这也为“我们需要学习多少数学”提供了一个方向。基础知识仍然需要扎实掌握，因为没有这些基础，我们很难判断机器的回答究竟是否合理。但学习数学的目标也可以更加丰富。随着机器越来越擅长执行标准化过程，我们可以把更多时间用于理解数学结构、建立概念之间的联系、提出问题和形成判断。

某些过去以熟练计算为主要目的的训练，将来也许会更多地表现为一种“思维体操”。这并不意味着这些训练失去意义，而是提醒我们进一步思考它们的作用：练习计算可以帮助我们建立必要的数学感觉，也可以帮助我们理解抽象概念；当计算本身越来越容易自动完成时，这些练习的意义更需要从更高层次去理解。

再进一步说，数学也是一种认识世界的方法。它要求我们区分假设与事实、直觉与证明、相关与因果、局部经验与一般结论。从这个意义上说，即使许多具体的计算工作逐渐交给机器，数学仍然具有工具之外的价值。

以上只是我们在这个阶段的一些思考。人工智能正在改变我们理解和使用数学的方式，也正在进入数学研究本身。面对这些变化，应该怎样学习数学，又应该怎样做数学，对我们而言，乃至对整个数学共同体而言，都仍然是值得继续探索的问题。

### 人工智能时代，我们应该怎样做数学？

传统上，我们很容易把数学学习理解成一个近似线性的过程：

**学习定义 → 掌握定理 → 理解证明 → 完成习题。**

数学研究则往往从问题出发，经历探索、猜想、验证和证明。

人工智能加入以后，这些基本环节仍然存在，但它们之间的工作分配正在发生变化。一种越来越容易实现的工作方式是：

**探索 → 猜想 → 人工智能辅助检索、计算与验证 → 尝试证明 → 人工审核 → 修改猜想或证明 → 再次探索。**

我们需要判断：什么问题值得研究？一个定义是否自然？这个猜想为什么值得相信？一个计算实验能够说明什么，又不能说明什么？证明中是否遗漏了条件？有没有没有想到的反例？一个结论能否推广？不同方法之间的差异究竟是技术上的，还是反映了更深的结构？

因此，在人与人工智能共同工作的环境中，人可能会更多地承担几种角色：问题的提出者、猜想的形成者、探索过程的组织者、结果的审核者，以及知识结构的整理者。

这种变化并不会削弱证明和推导的重要性。恰恰因为机器可以迅速生成大量形式完整、语言流畅、甚至十分“像数学”的内容，我们更需要理解一个严格的定义是什么，一个完整的证明需要哪些条件，以及什么样的证据足以支持一个数学结论。

2026 年发布的《莱顿人工智能与数学宣言》（*Leiden Declaration on Artificial Intelligence and Mathematics*）集中讨论了人工智能进入数学研究以后带来的这些问题。宣言将理解、清晰性和判断力，以及数学论证的透明性和独立可验证性，视为数学研究中值得维护的重要价值。[3] 它同时提醒我们，当前的自动化工具可能产生看似合理、实际上却不可靠甚至错误的论证；当自动化技术参与正式发表的数学研究时，论证和结果正确性的责任仍由人类作者承担。[3]

学生以后遇到的问题，很可能越来越多地变成：“我能不能判断眼前这个答案？”人工智能可以参与探索，可以提供候选结果，也可以帮助我们检查自己的工作；但接受什么、怀疑什么、怎样验证，以及最终为什么相信一个结论，仍然要求人作出判断。

因此，在人工智能时代，一种很朴素但可能越来越重要的能力是：

**当答案越来越容易生成时，我们仍然知道为什么相信一个答案。**

### 从知识的接受者，到知识的整理者：我们的实践

人工智能的加入，也使我们需要重新思考数学学习的过程。

今天的大学数学课程通常以教材、教学大纲、课堂讲授、习题和考试为基本结构。这套模式能够把经过长期积累形成的知识体系，以稳定、系统的方式传递给学生。与此同时，学生获得解释、例子和解题思路的渠道正在迅速增加。人工智能可以帮助我们查找资料、生成例子、比较不同解释、尝试不同思路，也可以参与检查推导和发现问题。

这使学习者有机会承担更主动的角色。

过去，一个学生通常先阅读教材，再完成题目；现在，他也可以自己整理知识，要求人工智能解释概念，比较不同教材中的定义，检查一段证明，然后重新组织成自己的表述。学习由此可以形成一个不断循环的过程：

**生成 → 阅读 → 质疑 → 验证 → 修改 → 再生成。**

人工智能显著降低了生成候选内容的成本，但候选内容本身并不等于理解。真正的学习仍然发生在阅读、质疑、验证和修改之中。要判断一个定义是否严谨，需要真正理解定义；要发现证明是否遗漏条件，需要理解定理成立的原因；要构造反例，需要知道一个结论可能在哪些边界上失效。

因此，“审核”本身也可以成为一种学习。

这份教材也试图把这种学习方式落实到具体的编写过程中。

教材的整理、讨论和编写本身也是共同学习的过程。课程课件帮助我们确定教学范围，成熟教材和经典教科书帮助我们确定理论深度，论文和公开资料帮助我们了解一些较新的发展；人工智能则参与部分内容生成、资料整理、解释、推导和审校。关于具体工具、参与范围以及责任划分，另见本书的《人工智能使用声明》。

在内容组织上，我们仍尽力尊重数学长期形成的基本结构：

**定义 → 命题与定理 → 证明 → 例子与反例 → 方法与应用。**

我们希望尽量说明一个概念为什么出现，它解决什么问题，与已有概念有什么关系；说明一个公式在什么条件下成立，一个证明依赖哪些假设，一个方法又会在什么地方失效。人工智能参与了生成过程，但所有内容仍需要经过阅读、核查、讨论和修改。

不同研究背景带来的差异，也使这种共同审核成为学习的一部分。一个人的疑问可能促成一段证明的重写，一个看似微小的错误也可能让我们重新检查整个推导。我们也希望读者保留同样的主动检查习惯：教材中的定义、证明、计算和一般性结论，都应当能够被重新检查和质疑。

因此，这份教材被设计成一份可以持续维护的数学学习记录。新的内容可以被加入，旧的表述可以被重写，错误可以被发现和修正，必要的修订过程也可以被保留下来。学习者也可以参与其中，成为教材的开发者、审稿人和共同维护者。

这种方式当然也有风险。人工智能会产生错误，持续更新可能带来新的疏漏，过度依赖工具也可能削弱独立探索和思考。因此，这种学习方式的效果仍然需要实践检验，而教材本身也应当继续接受检查、质疑和修改。

### 写在最后

人工智能究竟会怎样改变数学，我们今天还很难给出确定的答案。

现在的数学家、工程师和学生，已经拥有远强于过去的数学工具和计算工具。未来，也将如此。但工具能力的增长并不能替代我们对数学的理解和品味。当答案越来越容易获得时，理解答案、判断答案以及提出新的问题，会变得越来越重要。

我们希望通过这份教材学习的，不只是一些数学知识，也包括：

**如何提出问题，如何组织知识，如何理解定义，如何检查论证，如何发现错误，如何与工具合作，以及如何对自己的判断负责。**

Turing 在七十多年前说，我们只能看到前方不远的地方。或许，前方不远的地方也难以看见。只有不断前行，方能发现道路。

这份教材不试图回答人工智能时代数学教育的全部问题。它只是从一门课程、一些数学知识和一次共同学习的具体实践开始，试着向前走一点。

如果在这个过程中，我们和学习者都能够更认真地重新以一种新形式去学习和认识数学，那么这次尝试就已经有了意义。
